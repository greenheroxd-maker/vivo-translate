GAME LIVE TRANSLATOR - PROTOTIPO v0.1

1) Abre GameLiveTranslator.exe.
2) Pulsa "Seleccionar zona" y arrastra sobre el cuadro de dialogo del juego.
3) Pulsa "INICIAR TRADUCCION".
4) La traduccion aparece flotando encima del juego.

IMPORTANTE:
- Requiere Internet para Google Translate.
- Esta primera version usa OCR y es experimental.
- No modifica archivos del juego.
- Guarda traducciones repetidas en cache.

COMPILAR EN GITHUB:
Sube GameLiveTranslator.py, requirements.txt y la carpeta .github al repositorio.
Actions > Build Game Live Translator > Run workflow.
